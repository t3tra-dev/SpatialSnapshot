# SpatialSnapshot B3d

Blender 5.0 以降向けのインポートアドオンです. SSPS を含む `.heic` / `.heif` / `.mov` から, アクティブなシーンに収録ごとのコレクションを追加し, カメラ・メッシュ・投影画像・ワールド背景を作成します. Blender 5.0 で検証しています.

## インストール

repository root で CMake と C17 compiler を使って ZIP を作成します.

```sh
python3 Scripts/package-b3d.py
```

`.build/b3d/spatial_snapshot-0.1.0-<OS>-<CPU>.zip` を Blender の **Preferences → Add-ons → Install from Disk** からインストールして有効にします. ZIP には, その OS / CPU 向けの C 共有ライブラリ, 対応する C ソースとライセンスも入ります. 別の OS / CPU ではその環境でビルドしてください.

MOV の画像復号には **FFmpeg / FFprobe**, macOS 以外での HEIC 復号には **HEVC decoder 付き libheif** が必要です. macOS では標準の ImageIO を `sips` 経由で使います. ツールは自動検索し, 見つからない場合はアドオン設定でパスを指定します. ツールの自動ダウンロードやインストールは行いません.

```sh
# macOS (Homebrew)
brew install ffmpeg
# Ubuntu
sudo apt-get install ffmpeg libheif1 libheif-plugin-libde265
```

## 使い方

1. **File → Import → SpatialSnapshot**, または 3D View へファイルをドロップします. SSPS のないファイルや不正な binding はエラーにし, コレクションは追加しません.
2. アクティブなシーンの直下に `<ファイル名> · SSPS` コレクションを追加します. 既存のオブジェクト・カメラ・ワールド背景・レンダーサイズ・色管理・単位設定・FPS・タイムライン範囲を維持し, 新しいシーンは作成しません.
3. サイドバーの **SpatialSnapshot → 収録** でコレクションを選びます. **収録カメラと背景を表示** を押すと, その収録のカメラ・ワールド背景・レンダーサイズに切り替わります. **Material Preview** では Scene World を有効に, または **Rendered** 表示にしてください.
4. MOV はタイムラインを再生・スクラブします. 各コレクションの開始フレーム, 同期の有効・無効, キャッシュは独立しています. 複数の MOV を同じシーンで再生でき, 別の収録がアクティブなカメラのレンダーサイズを上書きすることはありません.

プロジェクトの FPS / FPS Base を使い, インポート時の現在フレームを収録の `0 ns` とします. 必要に応じてシーンの再生範囲を調整してください. SSPS の m 単位を読み込み先の単位スケールへ換算し, 重力を Blender の `-Z` へ揃えます. カメラ表示の縦横・上下も SSPS の重力から決め, 90° 単位でカメラのロールと内部パラメータ, レンダー解像度・画素の縦横比を一緒に変換します. HEIC の横長／縦長や画像の見た目で重力を推測しません. 保存された画素と投影材質は元の向きを保つため, メッシュと背景の位置はずれません. 真上・真下を向いた収録では元の表示方向を使い, 動画では最初に決めた方向を全フレームで維持します.

メッシュとワールドは同じカメラ投影と画像を使います. ワールドにはメッシュで隠れる部分も含めて画像全体を描くため, メッシュ境界の両側に同じ色があり, アンチエイリアスの隙間を防ぎます. 撮影画角の外は黒です. メッシュは発光材質です. 元画像に近い色で表示する場合は, シーンの表示変換を Standard, 露出を 0 にしてください.

動画では, Blender の経過時間から MOV の presentation timestamp を選び, 画像・camera・geometry を同じサンプルへ更新します. サンプル間は直前のサンプルを保持し, 範囲外は先頭／末尾を保持します. FPS を変更しても再生速度は変わりません. フレーム補間, 音声, 深度からの補間メッシュ生成は行いません.

## 保存と制約

静止画の画像と SSPS は `.blend` に埋め込みます. 動画の SSPS も埋め込みますが, 復号画像はアドオン設定のキャッシュディレクトリに保持します. 省略時は Blender の user data 配下 `SpatialSnapshotB3d` です. 動画の `.blend` を移動・共有するときは画像キャッシュも一緒に移し, サイドバーでパスを指定してください. 元の収録があれば **キャッシュを再作成**できます.

動画の再オープン・再生にはアドオンが必要です. 同期中のカメラと収録メッシュはフレーム変更で更新されるため, 手作業で変更するときは対象の収録の同期を無効にしてください. 動画を追加したシーンでは, レンダー中の更新に備え **Lock Interface** を有効にします. コレクションの名前や階層を変更しても同期は維持します. 旧実装で保存したシーン単位の収録データは, 読み込み時に既存コレクションへ移行します. 画像は SDR の RGB PNG に復号し, HDR の厳密な色再現や撮影位置以外から見た未撮影領域の復元は対象外です.

SSPS / binding の解析は `ctypes` から C ABI を呼び出します. C コアの検証・リソース上限がそのまま適用されます. 元ファイルは変更しません.

## 検証

`sh Scripts/check-b3d.sh` で C ライブラリのビルド, Python テスト, Blender のバックグラウンドでのインポート・レンダー・再オープンテストを実行します. Blender が PATH にない場合は `BLENDER_BIN` を指定できます. CI は macOS / Linux で ctypes reader・時刻変換テストと ZIP 作成を実行します.
